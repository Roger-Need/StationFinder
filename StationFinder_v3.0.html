About

StationFinder is a self-contained radio station database application. Load a station frequency schedule file and search by frequency. Filter by station name, mode, language, source, or on-air status. Optionally connect to an SDR program via WebSocket or CAT to track stations, scan a frequency range for active signals, and control the receiver in real time.

Buttons

Import FileLoad an Aoki, EiBi, HFCC, ILG Radio, SDR Console, swskeds or s1b schedule file. BandSelect a standard shortwave or medium wave band. Sets the frequency search to that band's range and switches to Range mode. ManualSearch manually by typing a frequency. Disconnects from SDR frequency tracking. FetchOne-shot read of the SDR VFO frequency and search for matching stations. TrackContinuously follow the SDR VFO frequency, updating the station list as the frequency changes. StepLeft-click to move forward one row in the table and send that frequency to the SDR. Right-click to step back one row. Starts from the row closest to the current VFO frequency, or the top of the table if the VFO is unknown or out of range. Wraps at both ends. Available in Range mode when the table has results. After a scan is stopped (Clear state), Step only walks through rows where a signal was detected, regardless of which filter is active. Scan / Stop ScanOpens the pre-scan panel showing a live spectrum preview for the current frequency range. Adjust sample rate, SNR threshold, and centre frequency before starting. Once running, the SDR scans the range and highlights stations where a signal is detected above the SNR threshold. Press Stop Scan to halt scanning — highlighted results remain. Press Clear to reset. Requires a WebSocket (SDRconnect) connection — not available with CAT or CI-V serial connections. Hop / Stop HopAutomatically steps through frequencies one by one, sending each to the SDR after the selected dwell time (1/2/4/6/8/10s). In Range mode with no scan running, hops through all visible table rows in order. After a scan is stopped (Clear state), hops only through frequencies where a signal was detected. Press again to stop; press once more to resume from the next frequency. Reset AllClear all search fields and filters and return to the full unfiltered list. Web Search 1Search the SDR VFO frequency on shortwave.live. Web Search 2Search the SDR VFO frequency on short-wave.info. Exact / Prefix / RangeSwitch frequency search mode. Exact matches a single frequency. Prefix matches all frequencies beginning with the entered digits. Range accepts a range e.g. 9000-10000 kHz and enables Scan, Step, and Hop. Show All / On NowToggle between showing all stations and only those currently on air based on UTC time. Pressing Clear to exit scan always resets to Show All. ModeFilter stations by transmission mode (AM, USB, CW etc.) Language / SourceFilter results by broadcast language or schedule source.

Keyboard Shortcuts

F or fJump to frequency search box. S or sJump to station search box. EnterRun search and release focus. EscapeClear and release focus from search box. Click rowTune the SDR receiver to that station's frequency and mode. Ctrl-click rowShow all fields for that station in a detail panel.

Unsupported Browser

StationFinder requires a Chromium-based browser such as Google Chrome or Microsoft Edge.

Features such as COM port access (CAT / CI-V) and file handling require APIs that are not available in your current browser.
